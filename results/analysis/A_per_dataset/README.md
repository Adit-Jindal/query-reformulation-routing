# A: per-dataset analysis

Generated by `analysis_A.py`. Re-running with the same stores and settings gives byte-identical CSV/TeX/JSON (see `A_hashes.json`).

## Settings

- stores: `store/scifact store/trec-covid store/nfcorpus store/fiqa store/webis-touche2020`
- retrievers: ['bm25', 'dense']; primary metric ndcg10 (also map100, recall100 in A1/A4)
- bootstrap B=5000, bootstrap seed=0 (paired over queries, resample indices shared per retriever x block)
- eps for helped/harmed: [0.05, 0.01] (helped: gain > eps; harmed: gain < -eps)
- LLM seeds used: [0, 1, 2] (cross-fit oracle needs >= 2)
- tie rule: **a0 wins ties** (exact seed-mean argmax, earliest action in order a0,prf,query2doc,hyde,decomp; identical to routing.py). Tolerance variants use |x-max| <= 1e-09; `share_split_tol` splits ties evenly.
- reference action for pairwise tests: query2doc
- git commit (HEAD of repo, uncommitted edits not captured): d0fef27a8e4229897380eea6d122b03dc9f6a6dd
- python 3.14.7, numpy 2.5.4, pandas 3.0.6

## Caveats

- TREC-COVID and Touche have ~50 queries: CIs are wide; n is reported in every table.
- nDCG@10 on TREC-COVID depends on incomplete judgments: see judged10_* in A9.
- Cross-fit oracle needs >= 2 seeds (here 3).
- a0 and PRF are seedless (zero seed variance); the noise correction only removes noise from LLM actions.
- Best fixed action is chosen in-sample on each block (it is NOT the train-selected one used in iteration_log).
- Cross-dataset results are descriptive, not a hypothesis test; ALL pools the same queries again, so ALL is excluded from Holm.
- Query-form shares use a heuristic classifier; validate by hand before quoting.
- Cost uses cost_table; latency measured under --workers>1 is inflated.

## Files and columns

### `A0_per_query.csv` (2740 rows)

- `retriever`: bm25 or dense
- `dataset`: dataset name; ALL = every query pooled
- `qid`: query id
- `query`: query text
- `n_words`: words in query
- `form`: heuristic query form
- `oracle_crossfit`: per-query best action chosen on other seeds, scored on held-out seed
- `oracle_naive`: per-query max of seed-mean (optimistic)
- `oracle_choice`: oracle best action (exact tie rule)
- `ndcg10_<action>`, `gain_<action>`, `map100_<action>`, `recall100_<action>`: seed-mean per-query values; `ndcg10_<llm action>_seed<k>`: single seed

### `A1_action_gains.csv` (180 rows)

- `retriever`: bm25 or dense
- `metric`: ndcg10 / map100 / recall100
- `dataset`: dataset name; ALL = every query pooled
- `n`: number of queries in the block
- `action`: a0, prf, query2doc, hyde, decomp
- `mean_score`: mean metric (seed-mean per query, then mean over queries)
- `mean_gain`: mean of (action - a0) per query
- `ci_lo`: 2.5% paired-bootstrap percentile
- `ci_hi`: 97.5% paired-bootstrap percentile
- `p_boot`: two-sided bootstrap p (same formula as routing.paired_bootstrap)
- `p_wilcoxon`: Wilcoxon signed-rank p on per-query gains (NaN if all zero)
- `cohens_d`: paired Cohen d = mean gain / SD of gain
- `p_boot_holm`: Holm across datasets (ALL excluded) per retriever x metric x action
- `p_wilcoxon_holm`: same, for the Wilcoxon p

### `A2_helped_harmed.csv` (96 rows)

- `retriever`: bm25 or dense
- `dataset`: dataset name; ALL = every query pooled
- `n`: number of queries in the block
- `eps`: threshold for helped/harmed
- `action`: a0, prf, query2doc, hyde, decomp
- `helped_rate`: fraction with gain > eps
- `harmed_rate`: fraction with gain < -eps
- `neutral_rate`: |gain| <= eps
- `net_rate`: helped - harmed
- `identical_rate`: |gain| < 1e-12
- `mean_gain_when_helped`: mean gain over helped queries
- `mean_loss_when_harmed`: mean gain over harmed queries (negative)

### `A3_win_share.csv` (60 rows)

- `retriever`: bm25 or dense
- `dataset`: dataset name; ALL = every query pooled
- `n`: number of queries in the block
- `action`: a0, prf, query2doc, hyde, decomp
- `share_exact_a0first`: win share, exact seed-mean argmax, ties go to the earliest action (a0); matches routing.py oracle_go_rate
- `share_a0first_tol`: same but ties = within 1e-9 of the max
- `share_split_tol`: ties within 1e-9 split evenly among tied actions
- `share_crossfit`: share of (query, seed) cross-fit picks (pick from other seeds)

### `A4_headroom.csv` (36 rows)

- `retriever`: bm25 or dense
- `metric`: ndcg10 / map100 / recall100
- `dataset`: dataset name; ALL = every query pooled
- `n`: number of queries in the block
- `a0`: mean a0 score
- `best_fixed_action`: action with the highest mean (in-sample, over all 5 incl. a0)
- `best_fixed`: its mean score
- `oracle_crossfit`: per-query best action chosen on other seeds, scored on held-out seed
- `oracle_naive`: per-query max of seed-mean (optimistic)
- `headroom_vs_a0`: oracle_crossfit - a0
- `headroom_vs_best_fixed`: oracle_crossfit - best_fixed
- `headroom_vs_best_fixed_ci_lo`: bootstrap CI of the per-query (oracle - best fixed)
- `headroom_vs_best_fixed_ci_hi`: 
- `best_fixed_gain_over_a0`: best_fixed - a0
- `best_fixed_share_of_oracle_gain`: (best_fixed - a0)/(oracle - a0)
- `optimism_gap`: oracle_naive - oracle_crossfit
- `oracle_go_rate`: share of queries where oracle best != a0 (exact tie rule)
- `oracle_go_rate_tol`: same with 1e-9 tolerance
- `tied_best_frac`: share of queries where >=2 actions tie for best

### `A5_heterogeneity.csv` (48 rows)

- `retriever`: bm25 or dense
- `dataset`: dataset name; ALL = every query pooled
- `n`: number of queries in the block
- `action`: a0, prf, query2doc, hyde, decomp
- `seedless`: True if the action has no seed variance (a0, prf)
- `n_seeds`: number of LLM seeds
- `mean_gain`: mean of (action - a0) per query
- `sd_gain_single_seed`: SD over queries of single-seed gain (avg over seeds)
- `sd_gain_seedmean`: SD over queries of seed-mean gain
- `within_seed_var`: mean over queries of the variance across seeds (ddof=1)
- `noise_share_single`: within_seed_var / total single-seed variance
- `var_true_single`: max(0, total single-seed var - within-seed var)
- `sd_true_single`: sqrt(var_true_single)  <- headline heterogeneity
- `var_true_seedmean`: max(0, var of seed-mean gain - within-seed var / n_seeds)
- `sd_true_seedmean`: sqrt of that
- `sd_true_over_abs_mean_gain`: sd_true_single / |mean gain|
